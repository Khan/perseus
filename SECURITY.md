# Security Policy

## Reporting a Vulnerability

If you believe you have found a security vulnerability in Perseus, please
report it through Khan Academy's HackerOne program:

**https://hackerone.com/khanacademy?type=team**

Please **do not** report security vulnerabilities through public GitHub issues,
pull requests, or discussions.

When reporting, please include as much of the following as you can:

- A description of the issue and its potential impact
- The affected package(s) and version(s) (e.g. `@khanacademy/perseus@x.y.z`)
- Steps to reproduce, or a proof of concept (such as a sample Perseus item)
- Any suggested mitigation or fix

The HackerOne program page describes the program's scope, rules, and how
reports are handled.

## Supported Versions

Security fixes are made on the `main` branch and released in the latest
version of each published package. We recommend always using the latest
release.
