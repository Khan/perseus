# Getting Started

This guide walks through integrating Perseus into your React application — from
installation through rendering your first interactive exercise.

> **Working in khan/frontend?** Skip the setup sections below. Import
> renderers from `@khan/component-perseus/perseus`, not `@khanacademy/perseus`
> (a lint rule enforces this). Importing it already calls `init()`, sets the
> dependencies, loads Perseus's styles and adds the i18n provider. You still:
>
> -   pass `dependencies`: `webappDependenciesV2` from `@khan/component-perseus`,
>     or `usePerseusDependencies()` from `@khan/classroom-perseus` in classroom;
> -   pass `kaLocale`;
> -   wrap `ServerItemRenderer` in an element with the `framework-perseus` class.
>
> Don't call `init()` or `setDependencies()` yourself: that would replace
> frontend's real dependencies across the whole app.

## Installation

Perseus is published as a set of scoped npm packages. At minimum, you'll need:

```bash
pnpm add @khanacademy/perseus @khanacademy/perseus-core
```

Perseus has a number of peer dependencies that must also be installed,
including React, Aphrodite, and the Wonder Blocks design system. See the full
list in the `peerDependencies` field of `@khanacademy/perseus/package.json`.

## Core Concepts

Before writing any code, it's worth understanding the two things Perseus needs
from you as a consumer:

1. **A `PerseusItem`** — the JSON content object describing the exercise,
   including its question, widgets, and hints.
2. **Dependencies** — a set of callbacks and components that Perseus delegates
   to the host application (analytics, URL generation, video loading, etc.).

## Providing Dependencies

Perseus uses two dependency mechanisms:

-   **`PerseusDependencies`** — passed via `setDependencies()` once at app
    startup. Covers things like TeX rendering, logging, and locale.
-   **`PerseusDependenciesV2`** (preferred) — provided via React context using
    `DependenciesContext`. Covers analytics, URL generation, and video loading.

A minimal setup looks like this:

```tsx
import {
    Dependencies,
    DependenciesContext,
    PerseusI18nContextProvider,
} from "@khanacademy/perseus";
import {mockStrings} from "@khanacademy/perseus/strings";
import type {
    PerseusDependencies,
    PerseusDependenciesV2,
} from "@khanacademy/perseus";

// Perseus's compiled styles. Load them once, anywhere in your app.
import "@khanacademy/perseus/styles.css";

const dependenciesV2: PerseusDependenciesV2 = {
    analytics: {
        onAnalyticsEvent: async (event) => {
            // Forward to your analytics system, or no-op
        },
    },
    generateUrl: ({url}) => url,
    useVideo: () => ({status: "loading"}),
};

const dependencies: PerseusDependencies = {
    /* ... */
};
Dependencies.setDependencies(dependencies);

function App() {
    return (
        // Required: Perseus throws without it outside tests and Storybook.
        // mockStrings is English; pass translated strings for other locales.
        <PerseusI18nContextProvider strings={mockStrings} locale="en">
            <DependenciesContext.Provider value={dependenciesV2}>
                {/* Perseus styles are scoped to this class. */}
                <div className="framework-perseus">
                    {/* Perseus components go here */}
                </div>
            </DependenciesContext.Provider>
        </PerseusI18nContextProvider>
    );
}
```

## Registering Widgets

Perseus widgets must be registered before they can be rendered. Call `init()`
once at app startup — it registers all widgets and handles any deprecated widget
replacements:

```tsx
import {init} from "@khanacademy/perseus";

init();
```

`init()` is idempotent, so calling it multiple times is safe.

## Parsing Content

Before rendering, parse and migrate any PerseusItem to the latest schema
version using `parseAndMigratePerseusItem` from `@khanacademy/perseus-core`.

_Note: Perseus content is often stored as a JSON serialized string. All Perseus
parsers can accept strings (which are first `JSON.parse()`'d before actual
parsing)._

```tsx
import {isFailure, parseAndMigratePerseusItem} from "@khanacademy/perseus-core";

const rawItem = {
    question: {
        /* ... */
    },
    hints: [],
};

const parseResult = parseAndMigratePerseusItem(rawItem);

if (isFailure(parseResult)) {
    console.error(parseResult.detail.message);
}

const item = parseResult.value;
```

This handles any schema migrations automatically, so older content works with
the latest version of Perseus.

## Rendering a PerseusItem

Use `ServerItemRenderer` to render a full item. Despite the name, it doesn't
talk to a server: "Server" means it can be rendered on the server. It never
scores anything; scoring is up to you (see below).

```tsx
import {ServerItemRenderer} from "@khanacademy/perseus";

function Exercise({item}) {
    return (
        <ServerItemRenderer
            item={item}
            problemNum={1}
            reviewMode={false}
            apiOptions={{}}
            dependencies={dependenciesV2}
        />
    );
}
```

### Getting the User's Answer and Scoring

`ServerItemRenderer` exposes a `getUserInput()` method via its ref. Call it
when the learner submits their answer. User input can then be scored using
functions in `@khanacademy/perseus-score`.

```tsx
import {useRef} from "react";
import {ServerItemRenderer} from "@khanacademy/perseus";
import {scorePerseusItem} from "@khanacademy/perseus-score";
import type {ServerItemRendererComponent} from "@khanacademy/perseus";
import type {PerseusItem} from "@khanacademy/perseus-core";

function Exercise({item}: {item: PerseusItem}) {
    const rendererRef = useRef<ServerItemRendererComponent>(null);

    function handleSubmit() {
        const userInput = rendererRef.current?.getUserInput();
        const score = scorePerseusItem(item.question, userInput, "en");
        console.log("The user's score:", score);
    }

    return (
        <>
            <ServerItemRenderer
                ref={rendererRef}
                item={item}
                problemNum={1}
                reviewMode={false}
                apiOptions={{}}
                dependencies={dependenciesV2}
            />
            <button onClick={handleSubmit}>Submit</button>
        </>
    );
}
```

### Where scoring happens

`scorePerseusItem` is a pure function, so it gives the same result in the
browser or on a server. Pick based on how much you need to trust the score:

-   **In the browser** (the example above): the quickest way to start, good for
    prototypes and low-stakes checks such as a Khanmigo activity. The item, with
    its answers, is in the browser, so don't use this where scores need to be
    trusted.
-   **On your own server:** keep the full item on the server, and send the
    browser an answerless copy from `splitPerseusItem(item)`. Post
    `getUserInput()` to your server and score it there:

    ```ts
    import {
        isFailure,
        parseAndMigrateUserInputMap,
    } from "@khanacademy/perseus-core";
    import {scorePerseusItem} from "@khanacademy/perseus-score";
    import type {PerseusItem} from "@khanacademy/perseus-core";

    export function scoreOnServer(item: PerseusItem, body: unknown) {
        // userInput comes from the browser, so validate it first.
        const userInput = parseAndMigrateUserInputMap(body);
        if (isFailure(userInput)) {
            return {status: 400};
        }
        return {
            status: 200,
            score: scorePerseusItem(item.question, userInput.value, "en"),
        };
    }
    ```

-   **On the Khan Academy backend:** content that counts toward mastery goes
    through the existing KA pipeline. Talk to the Perseus team.

The score is one of two shapes:

-   `{type: "points", earned, total}`: the answer is correct when
    `earned >= total`.
-   `{type: "invalid", message}`: the input isn't ready to score yet. That's
    not a wrong answer. A missing `message` means the input is empty.

To show the solutions after checking, re-render `ServerItemRenderer` with the
full item and `showSolutions="all"`.

## Rendering an Article

For long-form, read-only content, use `ArticleRenderer` instead:

```tsx
import {ArticleRenderer} from "@khanacademy/perseus";
import type {PerseusArticle} from "@khanacademy/perseus-core";

function Article({article: PerseusArticle}) {
    return <ArticleRenderer json={article} />;
}
```

Articles are never scored, but they can contain embedded "knowledge check"
widgets (`GradedGroup` / `GradedGroupSet`) that give learners in-line practice.
