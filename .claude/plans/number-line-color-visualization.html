Number-Line Color Migration — Before / After

LEMS-4269 · hardcoded KhanColors → Wonder Blocks semantic tokens

What changed, in one line: all green is gone. The interactive point, its hover state, the mobile dot, and the mobile inequality ray went from green to instructive blue. The static point went from blue to gray (it can't be dragged). Point edges are now a white knockout ring. The already-blue elements (highlighted first tick, labels, desktop ray) look identical in the default theme — their win is that they now theme correctly in Thunderblocks / dark instead of being a frozen hex.

Swatch cells are painted on each theme's real canvas color, so a white knockout ring or a hollow center reads the way it actually will in the widget.
